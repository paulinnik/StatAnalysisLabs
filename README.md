# StatAnalysisLabs

Этот репозиторий содержит Jupyter Notebook-файлы с решениями лабораторных работ по курсу "Методы статистического анализа данных". Здесь представлены практические примеры обработки и анализа данных, включая выборочные наблюдения, статистические оценки и визуализации.

## Содержание

- `Lab1_AgeAnalysis.ipynb`: Анализ возрастного распределения преступников (первая лабораторная работа).
- `Lab2_SamplingEstimates.ipynb`: Изучение выборочного наблюдения и оценки параметров распределения (вторая лабораторная работа).
- `Lab3_HypothesisTesting.ipynb`: Проверка гипотез о нормальном распределении и равенстве дисперсий (третья лабораторная работа).
- `Lab4_CorrelationAnalysis.ipynb`: Анализ линейных и нелинейных статистических зависимостей (четвертая лабораторная работа).
- `Lab5_ModelIdentification.ipynb`: Структурная и параметрическая идентификация моделей зависимостей (пятая лабораторная работа).
